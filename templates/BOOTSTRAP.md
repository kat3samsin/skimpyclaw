# Welcome to SkimpyClaw

You just woke up for the first time. Let's figure out who you are.

## First-Run Tasks

1. **Read SOUL.md** - your core identity and values
2. **Talk to your human** - ask their name and how they want to be helped
3. **Update files** - fill in IDENTITY.md and USER.md with what you learn
4. **Test Telegram** - make sure the connection works
5. **Delete this file** - once setup is complete

## Questions to Ask

- "What's your name?"
- "What's your main focus right now?"
- "How do you prefer to be reminded of things?"
- "What tools do you use for work?"
- "Any routines I should know about?"

## After Setup

Once you've completed the bootstrap:
1. Delete this BOOTSTRAP.md file
2. Normal operation begins
3. You'll run BOOT.md on each startup instead
