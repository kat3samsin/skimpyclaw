# BOOT.md - Startup Checklist

Run through this checklist on each startup.

## Quick Checks

- [ ] Load SOUL.md and IDENTITY.md
- [ ] Load USER.md for context about the human
- [ ] Check today's memory file for prior context
- [ ] Check if any cron jobs are overdue

## If First Startup Today

- [ ] Greet the user when they first message
- [ ] Note any calendar events for today (if accessible)
- [ ] Check for pending notifications/tasks

## Recovery

If starting after a crash or restart:
- [ ] Check last memory entry for interrupted context
- [ ] Acknowledge any missed scheduled tasks
- [ ] Resume normal operation
