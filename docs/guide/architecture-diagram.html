SkimpyClaw Architecture

Personal AI assistant — Fastify gateway, multi-provider agent, tool loop, coding-agent subprocess dispatch

Inputs & Triggers

  • • Telegram bot (grammY) — conversation history, /model, /new, /compact, typing indicator
  • • Discord bot (discord.js) — threaded coding-agent status
  • • CLI — skimpyclaw start|status|cron|tools|sandbox|model
  • • Dashboard — Preact/Vite SPA under /dashboard, Bearer-auth REST
  • • Cron — agentTurn · script · http payloads; prompt sources restricted to ~/.skimpyclaw/prompts/
  • • Heartbeat — 1hr keep-alive

Agent & Tool Loop

  • • runAgentTurn() assembles prompt, streams, handles tool loop
  • • runToolLoop() is unified across all providers — no per-provider loop logic
  • • Skills use progressive disclosure — names/descriptions only until invoked
  • • Context compaction triggers at maxContextTokens (default 100k)
  • • Exec approval tiers 2/3 require human confirmation with 5-min TTL
  • • Every turn logs to usage/YYYY-MM-DD.jsonl + audit trace

Providers

  • • Adapter-based routing (ProviderAdapter interface)
  • • Anthropic — OAuth or API key; MCP support; prompt caching
  • • Codex — ChatGPT OAuth via chatgpt.com/backend-api; MCP support
  • • OpenAI-compatible — OpenRouter, Groq, Together, OpenAI (no MCP)
  • • Kimi, Minimax — additional model providers
  • • Aliases: claude-fast/think/opus, codex5.3, kimi

Tools

  • • File ops — Read/Write/Glob path-restricted to allowedPaths
  • • Bash — risk-tier classifier, approval registry for tiers 2/3
  • • Browser — Playwright (chromium/firefox/webkit) — built-in
  • • Fetch — IP blocklist, hostname checks, redirect re-validation — built-in
  • • code_with_agent, code_with_team, check_code_agent — child-process coding CLIs
  • • MCP tools — dynamically discovered, see Extension Points card

Extension Points

  • • Skills — markdown at ~/.skimpyclaw/skills/<name>/SKILL.md; loaded at runtime, no recompile. Progressive-disclosure: names/descriptions injected, full content loaded on-demand.
  • • MCP servers — configured in ~/.mcporter/mcporter.json; auto-discovered every 5min; tools appear as mcp__<server>__<tool> with no code change.
  • • Skills extend behavior (prompt guidance). MCP extends capabilities (new tools).
  • • Built-in tools (File/Bash/Browser/Fetch/code-agents) are compiled in. Replacing them requires code changes — though Browser/Fetch could in principle be swapped for MCP equivalents.
  • • Anthropic + Codex providers forward MCP tools to the model; OpenAI-compatible non-Codex providers filter them out.

Security Boundaries

  • • Bearer auth on gateway (SHA-256 + timingSafeEqual)
  • • Config file 0600; secrets via ${ENV_VAR} or ${KEYCHAIN:…}
  • • Env sanitization strips API keys from child-process env
  • • Path validation on every file op against ToolConfig.allowedPaths
  • • Fetch tool blocks RFC1918, link-local, metadata IPs (re-checks on redirect)
  • • Optional sandbox (container/docker) for coding agents

Storage Layout

  • • ~/.skimpyclaw/config.json — runtime config (0600)
  • • ~/.skimpyclaw/agents/<name>/ — agent templates (SOUL, IDENTITY, USER, HEARTBEAT copied by default)
  • • ~/.skimpyclaw/skills/<name>/SKILL.md — skill content
  • • ~/.skimpyclaw/sessions/ — per-channel chat persistence
  • • ~/.skimpyclaw/logs/usage/, logs/audit/, logs/cron/, logs/code-agents/ — JSONL append-only
  • • ~/.skimpyclaw/prompts/ — whitelisted cron prompt source dir
